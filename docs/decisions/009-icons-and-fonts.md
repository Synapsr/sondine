# 009 — Icons and fonts in a public repository

Status: Proposed — 2026-11-02

## Context

The UI follows the Graphical "Sondine" theme (GUI.md), which selected Timeless
Grotesk (Allo since 2026-11-19) and Hugeicons filled. Téo chose Nucleo (`ui` and `micro-bold`)
instead of Hugeicons. The repository is public under AGPL-3.0.

## Decision

- **Icons.** Nucleo UI Fill 18 by default (closest to the theme's filled
  style), Nucleo Micro Bold for small stroke primitives. No `nucleo-*`
  dependency in the repository: a generated subset of at most 100 glyphs is
  committed behind one entry point (`packages/ui/src/icon`), each file with
  the Nucleo copyright notice. Only Téo regenerates the subset from his
  licensed install; contributors and CI build without a key. A check counts
  glyphs and verifies the notice.
- **Font.** Allo (since 2026-11-19, see the amendment below), under the SIL
  Open Font License 1.1, which allows embedding in apps and distribution in a
  public repository with the license next to the file. Bundled locally as
  WOFF2 (the app is offline), weights 400/500/600 from the variable range.
- `LICENSE` stays the verbatim AGPL-3.0 text. `NOTICE` carries an AGPL
  section 7 additional permission naming the Nucleo icon files and the font
  directory: Sondine may be conveyed combined with them under their own
  licenses, and they are not part of the Corresponding Source. It also lists
  every third-party asset with its license.

## First subset (M0)

- 60 glyphs, listed in `packages/ui/src/icon/icons.json`, generated by
  `packages/ui/scripts/generate-icons.mjs` and checked by `check-icons`.
- 64 since 2026-11-09: paperclip, pin, file and image for a conversation's
  context (ADR 024), generated at Téo's request from his licensed packages,
  at the versions the script pins, so the other 60 came out unchanged.
- 66 since 2026-11-09: chat (a speech bubble with a sparkle) and arrow-up,
  for the discussion with an agent (ADR 027), the same way.
- 67 since 2026-11-09: wifi for a private zone on « Ce réseau » (ADR 029),
  generated the same way.
- 68 since 2026-11-10: book-open (an open book) for the Journal view
  (ADR 028), generated the same way.
- 69 since 2026-11-23: tag (`IconTagFill18`) for tags on recordings
  (ADR 039), generated the same way.
- The font is the upright variable WOFF2 of the `allo-font` npm package,
  with its roundness axis set to 0 and every character kept (see the
  amendment of 2026-11-27); its source, the command that made it, and both
  sha256 are in `packages/ui/src/fonts/README.md`.

## Amendment — Allo (2026-11-19)

Téo chose Allo for the redesign (ADR 037): one sans family for every role,
without a serif. It replaces Timeless Grotesk, whose file and license left
the repository. Allo is Josh Puckett's redrawing of Inter, with optical size,
weight and roundness axes; its open license removes the earlier risk of a
paid or changed license.

## Amendment — Allo 1.1.0 at roundness 0 (2026-11-27)

The app takes the site's art direction (ADR 033's amendment): Allo 1.1.0
with its `ROND` axis fixed at 0, the face the site uses, in place of Allo
1.0.3 at its default roundness of 50. The file is made from the package's
variable WOFF2 with fontTools, which removes the axis; its named instances
move to roundness 0 first, so the iPhone app still finds `AlloVariable-*` by
name. It keeps every character of the source, where the site's copy is a
Latin cut, because transcripts can be in any language the font covers. The
Mac and the iPhone ship the same file, 218 KB instead of 448 KB.

## Consequences

- Swapping the icon set means regenerating the files behind the entry point;
  no screen imports a provider.
- The theme's Hugeicons variables become documentation only; the deviation is
  reported in the theme coverage.
- Allo's license is the SIL Open Font License; if it ever stops fitting, the
  fallback is Inter, which Allo is drawn from.
